Neutron Transport Computational Methods

Advanced deterministic and stochastic methods for reactor physics simulation

Introduction

Neutron transport theory describes the migration of neutrons through matter, governed by the linear Boltzmann equation. Accurate solution of this equation is fundamental to reactor core design, shielding analysis, and criticality safety.

This guide covers modern computational approaches used in production reactor analysis codes.

Deterministic Methods

Discrete Ordinates (SN)

The SN method discretizes the angular domain into a finite set of directions, converting the integro-differential Boltzmann equation into a system of coupled differential equations.

Key advantage: Systematic convergence with angular refinement. Challenge: Ray effects in void regions. 
# SN solver configuration
sn_config = {
    "order": 8,           # S8 quadrature
    "spatial_scheme": "diamond_difference",
    "acceleration": "DSA",  # Diffusion Synthetic Acceleration
    "convergence": 1e-6
}

Method of Characteristics (MOC)

MOC tracks neutrons along characteristic rays through the geometry, computing flux by integrating the transport equation along these paths.

# MOC ray tracing
def trace_characteristics(geometry, azimuthal_angles, polar_angles):
    rays = generate_rays(geometry, azimuthal_angles, polar_angles)
    for ray in rays:
        segments = intersect_geometry(ray, geometry)
        flux = integrate_along_ray(segments)
    return flux

Stochastic Methods

Monte Carlo

Monte Carlo simulates individual neutron histories statistically, providing exact solutions (within statistical uncertainty) for complex geometries.

Strengths: Exact geometry, continuous energy, complex physics. Weaknesses: Statistical noise, computational cost for deep penetration. 
# Monte Carlo criticality calculation
def monte_carlo_k_eff(geometry, n_cycles=500, n_particles=10000):
    keff_cycles = []
    for cycle in range(n_cycles):
        fission_sites = sample_fission_sites(geometry, n_particles)
        next_sites = transport_particles(fission_sites, geometry)
        keff = len(next_sites) / len(fission_sites)
        keff_cycles.append(keff)
    return statistics(keff_cycles)

High-Performance Computing

Parallelization Strategies

  • Domain decomposition: Spatial partitioning (MPI)
  • Energy/angle decomposition: Group/angle parallelism
  • Particle parallelism: History-based (Monte Carlo)
  • GPU acceleration: Sweep kernels, tally reduction
# MPI domain decomposition example
from mpi4py import MPI
comm = MPI.COMM_WORLD
rank = comm.Get_rank()
size = comm.Get_size()

local_domain = decompose_domain(global_domain, rank, size)
local_flux = sweep(local_domain)
global_flux = comm.allgather(local_flux)
